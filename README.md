# Steam AI Analytics Platform

AI-powered Steam review intelligence platform for sentiment analysis, player pain detection, and executive gaming insights.

---

## Overview

This project analyzes real Steam game reviews and transforms raw player feedback into actionable product intelligence.

The platform helps identify:

- Player sentiment trends
- Technical pain points
- Community frustration drivers
- Engagement signals
- Retention risks
- Executive-level gaming insights

Built with Python and Streamlit as an interactive analytics dashboard.

---

## Features

- Live Steam review fetching
- Sentiment analysis
- Player pain-point detection
- Executive intelligence layer
- Competitive intelligence
- Community risk analysis
- Interactive dashboard UI
- Drill-down analytics sections
- Review-based business insights

---

## Example Insights

The platform can automatically detect:

- Performance complaints
- Bug frequency
- Server instability
- Cheater-related frustration
- Monetization backlash
- Matchmaking and balancing concerns

It also generates executive-style summaries based on real review patterns.
